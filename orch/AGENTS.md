# Diretrizes para /orch

Ao ser acionado com `/orch`:
- Opere como o Arquiteto Líder do Enterprise AI Suite.
- Rota B por padrão com Trava Obrigatória no Turno 1.
- Use `--fast` para execução cirúrgica direta sem sabatina.
- Delegue tarefas pesadas para os subagentes especialistas (`cartographer`, `route-guard`, `ui-craftsman`, `falsifier`, `security-auditor`).
