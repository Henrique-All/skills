# 🧪 Test Forge — Engenharia de Testes Reais & Anti-Mock Fantasma

Skill especializada em testes de integração de API sem mocks vazios e testes E2E com Playwright cobrindo Desktop e Mobile.

## 🚀 Como Usar:
```bash
# Gerar teste de integração de rota de API:
node scripts/forge-api-test.js POST /api/orders --out test/orders.test.ts

# Gerar teste E2E tátil com Playwright:
node scripts/forge-e2e.js /checkout --out e2e/checkout.spec.ts

# Auditar qualidade dos testes existentes:
node scripts/test-audit.js test/
```

## 🧪 Testes da Skill:
```bash
npm test
```
